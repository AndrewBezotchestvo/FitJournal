# Аккаунты FitJournal на Play2Go

Рабочая точка входа — fitjournal_server.py. На установленном сервере start_fitjournal.py сначала обновляет папку fitjournal-release из ветки main и затем запускает её.

Открой /register, выбери логин и пароль длиной от 12 символов. После регистрации откроется личный дневник. Форма входа находится по /login. Кнопка «Выйти» завершает сеанс.

Для каждого пользователя сохраняются отдельные план, силовые, кардио, питание, замеры и настройки. Новые аккаунты начинают с пустого дневника. Стартовую неделю можно загрузить командой из папки проекта после регистрации:

```sh
python -m flask --app fitjournal_server:build_app seed-plan --username YOUR_LOGIN
```

Данные находятся в fitjournal-data/journal.sqlite3. Таблица users содержит уникальный логин, PBKDF2-хеш пароля с солью и время создания. Пароли не записываются в открытом виде. user_settings хранит цели пользователя, а user_id в таблицах дневника определяет владельца каждой записи.

Обновление существующей базы добавляет таблицы пользователей и столбцы владельца. Старые записи без владельца сохраняются с user_id=NULL и автоматически никому не выдаются. Если такие записи есть, назначение конкретному владельцу выполняется отдельно после проверки. Старое приложение TrainingTrackerFlask использует другую базу, которая этим обновлением не изменяется.

Доступ по текущему адресу Play2Go использует HTTP. Для работы с настоящими паролями и личными записями настрой HTTPS. После настройки TLS установи FITJOURNAL_HTTPS=1 для Secure-cookie. При прокси требуется согласовать обработку протокола с его конфигурацией. Восстановление пароля по почте в этой версии отсутствует.

Ограничение попыток входа и регистрации составляет 30 запросов за 5 минут на весь процесс. Это рассчитано на небольшой личный сервер с одним процессом Waitress. Не публикуй папку fitjournal-data и резервные копии в GitHub.

Проверки запускаются командой:

```sh
python -m unittest discover -s tests -p test_accounts.py -v
```

При входе и регистрации «Запомнить вход на этом устройстве» включено по умолчанию. При включённой опции браузер хранит вход до 180 дней. При отключённой опции cookie действует до завершения сеанса браузера, а серверный сеанс истекает через сутки. «Выйти» завершает текущий сеанс на сервере. После перехода со старой версии требуется один повторный вход.

Переключатель «Тема» доступен в шапке приложения и на экранах входа и регистрации. Выбор сохраняется в текущем браузере.
