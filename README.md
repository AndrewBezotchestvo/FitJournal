# FitJournal — локальный дневник тренировок

Python 3.10+; Flask 3; SQLite; Chart.js через CDN (для графиков нужен интернет).

## Установка

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть http://127.0.0.1:5000

При первом запуске создаётся `fitjournal.sqlite3`, автоматически добавляется примерный шестидневный план. Цели, замеры и меню можно заполнить через интерфейс. Все упражнения, дни, подходы, повторения, цели и блюда можно менять через интерфейс. После тренировки записывайте реальные подходы и веса. В меню "Замеры" добавляйте вес и талию, в "Питание" — съеденные блюда. Графики строятся из этих данных.

### Важно

Это приложение предназначено для локального личного использования. Не выставляйте его в публичный интернет без авторизации, HTTPS и защиты от CSRF. База SQLite хранится рядом с `app.py`; для резервного копирования остановите сервер и скопируйте файл `.sqlite3`. Для графиков нужен доступ к CDN Chart.js.
